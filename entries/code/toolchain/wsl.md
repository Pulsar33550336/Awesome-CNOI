## 简介

在 Windows 上运行 Linux 环境，用来对齐 Linux 的编译与运行行为。

## 许可证

仓库里的脚本与文档按 MIT 发布，但 WSL 本体随 Windows 分发，微软没有以 MIT 或其他开源许可发布 Windows 侧的组件。Linux 内核部分单独按 GPL-2.0 开源。
